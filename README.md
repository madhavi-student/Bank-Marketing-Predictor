## Project Description
Bank Marketing Predictor is a Machine Learning project
that predicts whether a customer will subscribe to a
bank's term deposit.

## Objective
The main objective of this project is to predict
customer responses to bank marketing campaigns using
Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Machine Learning

## Algorithm Used
Random Forest Classifier

## Features
- Loads the bank marketing dataset.
- Processes customer information.
- Trains a Machine Learning model.
- Predicts customer subscription.
- Evaluates model accuracy.
- Saves predictions in a CSV file.

## Project Files
- bank-predictor.py
- bank_predictions.csv
- README.md

## Implementation Steps
1. Load the bank marketing dataset.
2. Preprocess the customer data.
3. Split the dataset into training and testing data.
4. Train the Random Forest model.
5. Predict customer subscription.
6. Evaluate model performance.
7. Save predictions to a CSV file.

## How to Run
1. Install Python.
2. Install the required libraries:

   pip install pandas scikit-learn

3. Run the Python file:

   python bank-predictor.py

## Output
The model predicts whether a customer may subscribe
to a bank's term deposit.

The prediction results are saved in
bank_predictions.csv.

## Conclusion
This project uses Machine Learning to predict customer
